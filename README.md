# AcciAssist

A tool to provide assistance during an accident.

## Features

### For Citizens & Accident Victims:

*   **Advanced Accident Reporting:** Instantly send alerts directly to nearby hospitals.
*   **Live Location Services:** Uses GPS to pinpoint the accident location and auto-fill the street address.
*   **AI-Powered First Aid:** Receive AI-generated first aid advice based on incident details.
*   **Multimedia Evidence Capture:** Upload photos, use live video analysis (simulation), and use speech-to-text for hands-free descriptions.
*   **Smart Hospital Selection:** Automatically finds and suggests the nearest hospitals, with the option to choose another.
*   **Emergency Services Directory:** One-tap calling for national helplines (Police, Fire, Ambulance).
*   **Emergency Contacts:** Instantly notify loved ones with location and incident details.
*   **Patient Dashboard:** Access medical history, appointments, medications, and insurance details.

### For Emergency Professionals & Hospitals:

*   **Ambulance Dashboard:** Field input for patient information, vital signs, and notes.
*   **AI Tools for Paramedics:** Includes an AI-powered patient handover summary generator and AI-suggested specialist teams.
*   **Live Ambulance Tracking:** Real-time map tracking of incoming ambulances for hospitals.
*   **Hospital Management Dashboard:** Displays incoming patient alerts, live ambulance locations, and an overview of hospital resources.
*   **Doctor's Dashboard:** Real-time patient handover data, AI-generated summaries, and access to patient medical history.
*   **Administrative Management Portals:** Interactive portals for managing hospital staff, inventory, users, and donors.
